# نظرسنجی خرید اقساطی تلفن همراه یزدان‌پلاس

یک صفحه مستقل، راست‌چین و واکنش‌گرا برای نیازسنجی اعضای هیئت‌علمی و کارکنان دانشگاه یزد. ظاهر صفحه از رنگ، فونت، لوگو، فاصله‌گذاری و ساختار رابط سایت رسمی یزدان‌پلاس الهام گرفته شده است.

## محتوای بسته

- `index.html`: صفحه نظرسنجی
- `styles.css`: هویت بصری و نمایش موبایل/دسکتاپ
- `app.js`: اعتبارسنجی، پیشرفت فرم و ارسال پاسخ
- `api/submit.php`: ثبت یا به‌روزرسانی پاسخ بدون اطلاعات هویتی
- `api/results.php`: خروجی تجمیعی و محافظت‌شده نتایج
- `assets/`: لوگو و فونت مورد استفاده سایت رسمی

## استقرار سریع

نیازمندی‌ها: PHP 8.1 یا جدیدتر و افزونه `pdo_sqlite`.

1. کل پوشه را در مسیر دلخواه دامنه، برای نمونه `/survey/mobile/`، قرار دهید.
2. مسیر دیتابیس را ترجیحاً خارج از پوشه عمومی وب تنظیم کنید:

   `SURVEY_DB_PATH=/secure/path/yazdan-mobile-survey.sqlite`

3. یک توکن طولانی و تصادفی برای مشاهده نتایج تعریف کنید:

   `SURVEY_ADMIN_TOKEN=replace-with-a-long-random-secret`

4. به مسیر دیتابیس اجازه نوشتن توسط کاربر وب‌سرور بدهید.
5. آدرس نهایی را با پارامتر منبع در ایتا منتشر کنید:

   `https://yazdanplus.ir/survey/mobile/?utm_source=eitaa`

## دریافت نتایج

درخواست زیر خروجی تجمیعی هر سؤال را برمی‌گرداند:

```http
GET /survey/mobile/api/results.php
Authorization: Bearer YOUR_SURVEY_ADMIN_TOKEN
```

هیچ نام، شماره تماس، کد پرسنلی یا نشانی IP ذخیره نمی‌شود. برای جلوگیری نرم از ثبت تکراری، مرورگر یک شناسه تصادفی تولید می‌کند و سرور فقط هش آن را نگه می‌دارد. ارسال مجدد از همان مرورگر، پاسخ قبلی را به‌روزرسانی می‌کند.

## اتصال به سامانه فعلی

اگر تیم فنی ترجیح می‌دهد ثبت پاسخ‌ها در بک‌اند فعلی یزدان‌پلاس انجام شود، فقط کافی است مسیر `endpoint` در انتهای `index.html` تغییر کند. قرارداد ورودی API:

```json
{
  "priceRange": "80_120",
  "monthlyPayment": "8_12",
  "term": "12",
  "downPayment": "under_25",
  "respondentToken": "random-browser-token",
  "source": "eitaa"
}
```

پاسخ موفق مورد انتظار:

```json
{ "ok": true }
```

برای دقت بالاتر و محدودکردن نظرسنجی به اعضای دانشگاه، تیم فنی می‌تواند همین صفحه را پشت ورود فعلی یزدان‌پلاس قرار دهد و شناسه ناشناس پاسخ‌دهنده را در سمت سرور از حساب ورودشده استخراج کند.
